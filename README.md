# Explainable AI (XAI) for Telecom Customer Churn

## Project Overview
This repository contains the code and methodology for analyzing telecom customer churn through the lens of Explainable AI (XAI). Using an XGBoost classification model paired with SHAP (SHapley Additive exPlanations), this research moves beyond standard binary prediction. 

It mathematically isolates and explains the specific behavioral triggers—such as tenure length, contract type, and billing history—that precede a customer's decision to discontinue service. This repository serves as the technical foundation for our ongoing research into actionable, data-driven retention strategies.

## Repository Structure
* `model.py` - The core Python script containing the data preprocessing, XGBoost model training, and SHAP value generation.
* `requirements.txt` - The list of dependencies required to execute the pipeline.
* `assets/` - Directory containing visualizations generated by the model.

## Dataset
This project utilizes the **Maven Communications Churn Dataset**. To ensure data integrity and avoid local file path issues, the dataset is dynamically fetched directly from Kaggle's servers via the `kagglehub` API upon running the script.
